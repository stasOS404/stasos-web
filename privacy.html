Кратко объясняю, какие данные затрагивают функции сайта. Последнее обновление: 25 ноября 2026.

01 / СБОР

Сайт не просит регистрацию

Сайт не содержит формы создания аккаунта и не сохраняет введённый ключ на сервере сайта. Избранное в Roblox-библиотеке хранится только в локальном хранилище твоего браузера.

02 / ПРОВЕРКА КЛЮЧА

Проверка выполняется на твоём компьютере

Форма проверки обращается к локальному сервису по адресу 127.0.0.1:8000. Введённый ключ передаётся только этому сервису в рамках запроса проверки. Если сервис не запущен, сайт показывает, что проверка недоступна.

03 / ВНЕШНИЕ СЕРВИСЫ

Telegram и шрифты

Ссылки Telegram открывают внешний сервис. Шрифты могут загружаться с Google Fonts. Их работа регулируется политиками соответствующих поставщиков.

04 / ВЫБОР

Очистка данных

Избранное можно очистить, удалив данные сайта в настройках браузера. Не вводи в формы сведения, которыми не хочешь делиться с локальной программой на своём компьютере.

05 / ВОПРОСЫ

Связаться с автором

Проект ведёт один автор — stas. Вопросы о сайте можно направить через Telegram-бота.
